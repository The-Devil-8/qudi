# Image Regeneration

This document details the techniques and implementation of the `ImageRebuildLogic` module, responsible for reading generic Qudi confocal `.dat` files (such as those generated by the `CellSegmentationLogic`) and rebuilding the visual representation of the confocal scan.

## Background
The raw data generated by the confocal logic is stored as flat `.dat` files. These files contain header lines (prefixed with `#`) detailing the scan parameters, followed by tab-separated numerical columns corresponding to:
- X position
- Y position
- Z position
- Fluorescence Counts (and optionally other counting channels)

When filtering data (e.g., stripping out regions outside of a target cell), the 2D spatial context is temporarily flattened into this 1D list format to match the original saving convention. `ImageRebuildLogic` exists to reconstruct the 2D spatial matrices from these 1D lists so they can be visually displayed or fed back into other image analysis modules.

## Pipeline

The `ImageRebuildLogic` module implements the following pipeline:

### 1. Data Parsing
The module reads the `.dat` file line-by-line. It skips all header lines starting with `#` (or metadata lines that don't begin with scientific notation). 

It loads the remaining block of numerical data into a numpy array. The data columns (X, Y, Z, Counts) are extracted into 1D arrays.

### 2. Spatial Grid Reconstruction
Because confocal scans are performed on a regular grid (e.g., $N \times M$ pixels), the module computes the unique X and Y coordinates to determine the original resolution (`nx`, `ny`).

It then reshapes the 1D arrays into 2D spatial matrices of shape `(ny, nx)`:
- `image[:, :, 0]` = X grid
- `image[:, :, 1]` = Y grid
- `image[:, :, 2]` = Z grid
- `image[:, :, 3]` = Fluorescence Counts

### 3. Visual Display Generation
The rebuilt spatial image is passed to a plotting backend (e.g., `matplotlib`). 

The module extracts the physical bounds (extent) of the scan from the `X` and `Y` grids to properly scale the axes in micrometers ($\mu$m). The fluorescence counts are rendered using a perceptually uniform colormap (such as `inferno`), matching the Qudi GUI's default aesthetics. 

The resulting figure can be saved to disk as a `.png` or `.pdf` artifact, providing clear visual verification of data filtering techniques (like cell boundary isolation) before proceeding to candidate identification in the automation pipeline.
